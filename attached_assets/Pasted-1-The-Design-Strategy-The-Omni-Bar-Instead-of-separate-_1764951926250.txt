1. The Design Strategy: "The Omni-Bar"
Instead of separate inputs, we will build a single floating control bar.

Consolidated: Search, Status Filter, and Sort Order live in one container.

Sticky: It should stick to the top of the scrollable area (under the stats) so investors can filter without scrolling back up.

Visuals: White background, rounded corners (rounded-full or rounded-xl), slight shadow, and internal vertical dividers.

2. The Stats Row (Simplification)
Your current stats cards are huge. In a split-view layout, vertical space is precious. We should shrink these into a "Slim Stats Ribbon" that sits above the toolbar.

3. The Code Implementation

Design Requirements:

The Omni-Bar: Create a cohesive "pill-shaped" container that groups the Search Input, Status Filter, and Search Button together. It should have a light gray border and rounded corners.

Slim Stats: Instead of the 4 large cards, move the stats (Total Properties, Total Equity, etc.) into a slim, single-line horizontal list just above the search bar. Use small colored dots (legend style) to distinguish them.

Sticky Positioning: The toolbar must use sticky top-0 and backdrop-blur so it stays visible when the user scrolls down the list of properties.

Layout: On Desktop, justify the Search Bar to the left and the Sort Dropdown to the right.
