1. Card Size + Layout Improvements
Make cards shorter

Right now the cards are tall, mostly because of:

Price row

Beds/Baths/Sqft row

Equity row

Purchase price row

Fix:
Condense all secondary info into a single line and only show:

Beds

Baths

Sqft

City/State

Everything else can be revealed in a hover state or details modal.

Use a tighter grid

Your spacing is Apple-clean but slightly too wide for large sets.
Use:

16px outer card padding

12px vertical spacing

3-column grid on desktop

2-column grid on tablet

1-column on mobile

This alone lets you fit 25+ cards comfortably.

2. Image Enhancements
Make the photo the hero

Right now the image feels slightly compressed.
Use:

Full-width image

Rounded corners on top only

16:9 ratio for consistency

Subtle overlay gradient at bottom for text visibility

Add Apple-style soft shadow inside the image

Add status badge inside the photo

Instead of above the card, place “Ready Funding” badge top left corner of image, floating on the photo.

3. Improve Visual Hierarchy (Airbnb Style)
Property Address = Primary

Bold, 16px, but keep line length tight.

Price or Equity = Secondary

Use:

Large green number for equity

Smaller muted number for purchase price

Use Multi-tone Typography

Apple and Airbnb both depend on:

Bold black for primary

Muted gray for secondary

Color-coded highlights (green, blue)

Everything needs a clear role.
