FIX 1 — Hero photo height and crop:
Find the hero outer container div.
It currently has something like:
  h-[56vw] min-h-[260px] max-h-[420px]
  or a style with fixed height

Change to:
  className="relative w-full overflow-hidden
    h-[45vw] min-h-[320px] max-h-[600px]
    lg:h-[70vh] lg:min-h-[500px] lg:max-h-[700px]"

FIX 2 — Photo object position:
The img tag inside the hero likely has
object-fit: cover but object-position defaults
to "center" which crops the top of the house.

Find the hero img tag and change/add:
  className="... object-cover object-center"
  
Change object-position to show the house properly:
  style={{ objectPosition: "50% 40%" }}

This shifts the crop slightly upward so the full
front of the house is visible instead of just
the roofline.

Find the element immediately after the hero div
and remove any mt-* or pt-* that's creating
the gap on mobile:
  Change: mt-12 or mt-16 or pt-12 → mt-0

Also check if the hero div itself has mb-* — 
remove it.
